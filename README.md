#Formula Student Dashboard
##Quick download guide
To run this app on a linux machine you need the following installations
1)sudo apt install build-essential cmake
2)sudo apt install qt6-base-dev qt6-declarative-dev libqt6serialport6-dev
3)sudo apt install qml6-module-qtquick qml6-module-qtquick-controls qml6-module-qtquick-layouts qml6-module-qtquick-window
